# jwu: приложить файлы к задаче

Загрузи `skill_view(name="jwu-hermes/jwu-session-init")`, если в сессии не подтверждены проект и правила. Не обходи `⛔`. Только Jira/Support; GitHub Issues не поддерживает этот способ, для `local` не делай внешних вызовов. MCP — только после сверки привязки, с `workspace=slug`; CLI — `jwu --workspace SLUG …` и явный `terminal(workdir=<проект>)`. Пути, ключ и тексты передавай через argv либо отдельно экранируй (`shlex.quote`).

1. Собери точные абсолютные пути локальных файлов, ничего не догружай из интернета. Проверь ключ задачи и доступность всех файлов. Не загружай секреты/креды или запрещённые данными контура материалы. HAR, логи и выгрузки могут включать токены, куки, телефоны и переписку; предложи проверить и очистить их. Не выводи сырые секреты в чат.
2. Превью: `jwu_issue_attach(key, paths, dry_run=True, workspace=slug)` возвращает `files` (`exists`, `size`) и `client_facing`; `ok: false` с `dry_run: true` ожидаемо. CLI: `issue attach KEY FILE … --json` **без** `--yes` — безопасное превью с `reason=confirm_required`, именами и размерами, но без `client_facing`. Подтверди внутреннюю/Support маршрутизацию по проверенным правилам контура и ключу; если не можешь, не загружай до выяснения. Если хотя бы одного файла нет, остановись, не отправляй часть.
3. Покажи ключ, имена, размеры и предупреждение: увидят все с доступом к задаче, в Support — **клиент**, удалить через jwu нельзя. Спроси явное «да» (`clarify`, если есть, иначе в чате). При изменении задачи, списка или файлов повтори превью.
4. Только после «да»: `jwu_issue_attach(..., dry_run=False)` или `issue attach KEY FILE … --yes --json`. Прочитай назад `jwu_attachments(key)` / `attachments KEY --json` и сверь id и имена; при частичном или неясном результате не повторяй загрузку вслепую. Верни подтверждённые имена и id. Если уже есть относящаяся к задаче работа, запиши итог (`job add ID TEXT --kind note`), без содержимого файлов.

Скачивание — отдельный запрос: `attachments KEY --download`. Этот скилл не отправляет комментарий и не создаёт задачу.
