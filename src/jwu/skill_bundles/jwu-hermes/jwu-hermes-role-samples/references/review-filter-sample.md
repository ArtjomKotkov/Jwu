# review-filter-sample

Второй технический проход по чужому PR. Вход: находки ревьювера, требования и правила, проверенные target и PR-дифф с номерами строк, существующие комментарии и при наличии история после независимого прохода. Не обновляй базу сам и ничего не публикуй.

Сверь каждую находку с кодом: `new` — внесена изменением; `made-reachable` — раньше проблема была недостижима по этому пути, покажи новый путь; `pre-existing` — PR её не меняет, оставь только для сводки. Убери дубли с указанием треда, неподтверждённые выводы, мелочи и то, что вне задачи. В `light` оставь только блокирующее и критичное. Если базы или доказательств не хватает, отметь, что проверить не удалось.

Верни подтверждённые находки с тяжестью и происхождением, сценарием → последствием → просьбой, доказательством из базы и диффа и техническим черновиком. Проверь якоря: `path:line` в numbered-диффе (новая сторона; для удалённой строки — старая, `FROM`, `REMOVED`), `reply_to` с ID треда или общий комментарий. Ответ на вопрос автора — первым. Отдельно перечисли отброшенное с причинами и `pre-existing`. Обоснуй рекомендуемый статус: `NEEDS_WORK` при блокерах, `APPROVED` только при достаточном покрытии без блокеров, иначе не предлагай статус. Не редактируй голос и не записывай результат сам.
