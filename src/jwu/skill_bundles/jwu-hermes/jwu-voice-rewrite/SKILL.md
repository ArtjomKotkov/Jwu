# jwu: переписать текст голосом пользователя

Это редактура готового текста, не сбор фактов и не отправка. Если проект и правила не подтверждены, загрузи `skill_view(name="jwu-hermes/jwu-session-init")`. MCP только после сверки, с `workspace=slug`; CLI — `jwu --workspace SLUG …`, явный `terminal(workdir=<проект>)`; аргументы передавай argv или экранируй каждый отдельно (`shlex.quote`).

1. **Чтение профиля без создания.** Используй уже прочитанный для этого контура `profile_md`; иначе читай существующий `$XDG_DATA_HOME/jwu/voice/<slug>/profile.md` напрямую через `read_file` (если `XDG_DATA_HOME` не задан или пуст, корень — `~/.local/share`). Разреши путь в том же окружении, где запущен CLI jwu. Если файл отсутствует, недоступен или путь не подтверждён, не вызывай инструменты показа профиля: они могут создать шаблон. Верни нейтральный технический черновик без имитации голоса; создание профиля — отдельный согласованный запрос через `jwu-voice-profile`. Канал — по контексту (`pr_comment`, `pr_reply`, `jira_comment`, `support_client`, `commit`, `message` и т. п.); только если выбор сильно меняет форму, уточни (`clarify` или чат), иначе возьми наиболее вероятный.
2. Если профиль есть, проверь точное имя `voice.agent` в этом воркспейсе (штатное — `voice-writer-sample`). Сначала ищи доверенную Hermes-адаптацию этого имени. Для штатного имени без своей адаптации загрузи `skill_view(name="jwu-hermes/jwu-hermes-role-samples", file_path="references/voice-writer-sample.md")`. По умолчанию перепиши в текущей сессии: ручные правила → «Анализ корпуса» → журнал правок. Для настроенной роли или отдельного прохода, запрошенного вызывающим скиллом, передай точные инструкции как `context` одного ограниченного `delegate_task` вместе с существующим профилем, `draft`, `channel`, `audience`, контекстом и ограничениями. Голос не читает профиль сам, не использует инструменты, не пишет в сервисы и не собирает корпус. Если нет точной роли или делегации, применяй профиль сам без подмены роли и не заявляй отдельный проход.
3. Меняй длину, порядок, обращения, обороты и оформление. Смысл, факты, уверенность, выводы, имена, ссылки и номера сохрани. На прямую просьбу выдай только текст для копирования; если пришлось трактовать неоднозначность или сжать — одна строка отдельно. Для вызывающего скилла верни черновик, не отправляй.
4. «Не похоже на меня» — только теперь `jwu_voice_examples(channel, limit=8)` / `voice examples CHANNEL --limit 8 --json`; сравни, перепиши, в одной строке объясни разницу. Для настроенной роли передай `recheck`, `previous`, `remark` и примеры. Не запускай сбор корпуса автоматически.
5. Для системного отличия предложи правило; если пользователь исправил или отклонил текст, отдельно спроси «Записать правку в профиль голоса?». Только после «да»: `jwu_voice_feedback(channel, verdict, before, after, reason, audience=…)` или `voice feedback --channel CHANNEL --verdict edited|rejected --before TEXT [--after TEXT --reason TEXT --audience AUDIENCE]` (выбрать один verdict). Проверь запись чтением `profile_path`/`profile`; не редактируй профиль напрямую.

Отправку делает профильный скилл с собственным подтверждением.
