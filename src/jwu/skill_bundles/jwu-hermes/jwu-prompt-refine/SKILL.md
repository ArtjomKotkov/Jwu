# jwu: собрать промпт для другой сессии

Готовь самостоятельное задание для исполнителя без текущего контекста. Не выполняй его, не меняй код, не запускай сборки и не коммить. Единственная запись — файл промпта в scratch. Если вопрос на две минуты, предложи выполнить вместо оформления, но не переключайся без согласия. Обычное поручение текущей сессии сюда не относится.

1. Возьми исходник из сообщения, указанного файла (`read_file`) или доступного треда. В контуре jwu при отсутствии подтверждённых правил и проекта загрузи `skill_view(name="jwu-hermes/jwu-session-init")`. Используй подтверждённые `paths` и теговые правила. MCP необязателен; только при подтверждённом совпадении с cwd. В CLI — `jwu --workspace SLUG workspace paths` и `rules --tag TAG --json` с явным `terminal(workdir=<проект>)`; динамические аргументы передавай argv или экранируй отдельно.
2. Только чтением (`search_files`, `read_file`, при наличии проверенный MCP индекса кода) найди файлы, функции и строки, рабочий аналог, расположение и стиль тестов, обязательные запреты и гайды. Что ответит репозиторий, не спрашивай. Не подтверждённое помечай как «выяснить по ходу» или явное допущение.
3. Проверь приёмку, границы, обязательное против желательного, точку изменения, способ проверки и данные, противоречия, скрытые допущения и объём. Спроси до 3–4 вопросов, только если ответы меняют работу. `clarify`, если доступен, иначе коротким сообщением; рекомендуемый вариант первым. Если вопросов нет, сразу оформляй.
4. Собери Markdown: краткий заголовок и контекст (репозиторий, пакет, версия/установка, если нужны); повод или симптом с точным воспроизведением; ориентиры `path:line` и образец; требования по приоритету; качество/тесты; «Чего НЕ делать»; проверка на реальных данных и критерии успеха; после реализации — установка/перезапуск, если нужны. Убери пустые секции, сохрани язык пользователя, назови реальные грабли вместо выдуманных.
5. `write_file` в scratch текущей среды: `<краткое-имя>-prompt.md` (абсолютный путь вне репозитория). Верни путь и коротко — что уточнил и какие допущения зафиксировал. Полотно в чат не дублируй.

Понятную задачу начать — `jwu-start-job`; завести карточку, а не промпт — `jwu-task-create`.
