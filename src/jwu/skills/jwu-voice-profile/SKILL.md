# jwu: анализ голоса в профиль

## Overview

Агент голоса пишет внешние тексты от имени пользователя по **профилю** воркспейса
(`~/.local/share/jwu/voice/<slug>/profile.md`). Этот скилл один раз разбирает корпус
реальных текстов пользователя и сохраняет в профиль раздел **«Анализ корпуса»** — правила
по каналам. Дальше агент в примеры не лезет, пока пользователь не скажет «не похоже на
меня». Пересобирать — когда корпус заметно вырос или анализ устарел
(`analysis.stale` в `jwu_voice_profile`).

Наружу ничего не пишется. Профиль — локальный файл, сохраняется только после «да».

> **MCP-first.** `jwu_voice_profile`, `jwu_voice_examples`, `jwu_voice_analysis_save`,
> `jwu_voice_collect`. Bash-фолбэк: `jwu voice show --json`,
> `jwu voice examples <канал> --limit 40 --json`, `jwu voice analysis -f <файл> --channels a,b`,
> `jwu voice collect`.

## Шаги

1. **Что есть.** `jwu_voice_profile()` → `corpus` (сколько текстов по каналам),
   `analysis` (есть ли, когда, по каким каналам), `profile_md` (ручные правила — их не
   противоречь). Корпус пустой или старый — предложи `jwu_voice_collect()` (читает
   Bitbucket/Jira/git, долго) и дождись согласия.
2. **Тексты по каналам.** Для каждого канала, где текстов ≥ 5:
   `jwu_voice_examples(channel, limit=40)`; для `sdesk_client` — с `audience="client"`.
   Каналы с < 5 текстами в анализ не бери — скажи, что для них агент будет смотреть примеры.
3. **Разбери каждый канал по фактам текстов**, не по общим представлениям о хорошем стиле:
   - длина: типично сколько предложений / строк, бывает ли длиннее;
   - порядок мыслей: с чего начинает (факт, сценарий, вопрос, «поправил»), чем заканчивает;
   - обращение и регистр: «ты»/«вы»/безлично, насколько прямо, есть ли вежливые обороты;
   - типичные обороты и слова — 2–4 короткие цитаты из текстов;
   - оформление: пунктуация, списки, markdown, `код`, ссылки, эмодзи, заглавные;
   - чего в текстах **нет** (не бывает «возможно, стоит», нет приветствий и т.п.);
   - для `commit`: формат темы (префикс задачи, тип, язык), есть ли тело.
   Правило пиши, только если оно видно минимум в нескольких текстах. Расходится с ручным
   правилом профиля — не перетирай, вынеси пользователю вопросом.
4. **Собери markdown**: `### Общее` (что одинаково во всех каналах) и `### <канал>
   (N текстов)` на каждый канал — короткими пунктами, с цитатами-примерами. Без
   персональных данных сверх необходимого (номера задач и имена коллег из цитат убирай).
5. **Покажи пользователю целиком** и спроси «сохранить в профиль?». Правки — учти и
   покажи снова.
6. **«да» →** `jwu_voice_analysis_save(markdown, channels=[…])` — раздел заменяется
   целиком, ручные правила и журнал правок не трогаются. Скажи, где файл
   (`profile_path`) и что править его можно руками.

## Чего не делать

- Сохранять без «да».
- Выводить правила из переписки с ассистентом — только корпус.
- Придумывать правило по одному тексту или «как принято писать».
- Перетирать ручные правила профиля — они главнее анализа.
