# Штатные роли jwu в Hermes

Это переносимые инструкции, не отдельные модели или типы субагентов. Сначала выбери имя по правилам подтверждённого воркспейса и вызывающего скилла. Предпочти доверенную Hermes-адаптацию с точно таким именем, если она уже настроена. Если её нет, используй штатную инструкцию только при совпадении имени:

| Имя | `file_path` для `skill_view(name="jwu-hermes-role-samples", file_path=…)` |
| --- | --- |
| `reviewer-jwu-sample` | `references/reviewer-jwu-sample.md` |
| `review-filter-sample` | `references/review-filter-sample.md` |
| `voice-writer-sample` | `references/voice-writer-sample.md` |

Если `skill_view` не видит каталог в чате воркера, прочитай `SKILL.md` и указанный файл через `read_file` из проверенного каталога `.hermes/skills/jwu-hermes-role-samples/` в репозитории Jwu или `jwu/skills/jwu-hermes-role-samples/` в установленном пакете. Не меняй рабочую папку задачи. Нет точной пользовательской роли — назови ограничение и предложи согласовать штатную; не подменяй имя и не запускай Claude/Codex. Для голоса без подтверждённой роли можно вычитать текст в текущей сессии по уже прочитанному профилю, не заявляя отдельный проход.

Передай инструкции конкретной роли как `context` отдельного ограниченного `delegate_task` с проверенными входами и минимальным доступом. При недоступной делегации применяй их последовательно и назови проход самостоятельным. Ревьюер, фильтр и голос — разные проходы. Роли возвращают текст и не публикуют, не меняют Git, статусы, CI, профиль или журнал. Артефакт сохраняет вызывающий скилл по правилам своего процесса. Не передавай секреты; голос получает существующий профиль как вход, ему инструменты не нужны. Без профиля верни нейтральный технический черновик.

## Обнаружение в чистой установке

- В проверенном клоне Jwu используй проектные скиллы: `hermes skills trust <корень Jwu>` и сессия внутри этого клона. Каталог в `.hermes/skills/` ссылается на поставляемую копию.
- Для обнаружения вне клона скопируй **только** каталог `jwu-hermes-role-samples` целиком (вместе с `references/`) из `jwu/skills/` установленного пакета или из `src/jwu/skills/` проверенного клона в `skills/` активного Hermes home (`$HERMES_HOME`, по умолчанию `~/.hermes`). Не обновляй поверх существующей локальной адаптации. Проверь `hermes skills list` и загрузку reference через `skill_view`. Остальные скиллы в `jwu/skills/` не обязательно адаптированы для Hermes.
