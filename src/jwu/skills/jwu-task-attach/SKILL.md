# jwu: приложить файлы к задаче

> **Воркспейс = где лежит код.** Контур определяется по текущей папке, проверить —
> `jwu_workspace_current()`; правила контура — в `rules_md`, **записи `⛔ ЗАПРЕТ`
> обязательны к исполнению** (например, запрет выкладывать дампы клиентских данных).
>
> **Провайдер**: загрузка вложений есть у `jira`. GitHub REST API прикладывать файлы
> к Issue не умеет — инструмент честно откажет.

## Главное правило

**Вложение не уходит без явного «да».** Его увидят все, у кого есть доступ к задаче,
а в SDESK — **клиент**. Удалить вложение через jwu нельзя.

**Скажи, ЧТО именно уедет.** har-файлы, логи и выгрузки регулярно содержат токены,
куки, номера телефонов и переписку. Перед отправкой назови файлы и предупреди
о содержимом; если это har или дамп — предложи пользователю проверить его или
почистить чувствительные поля.

## Инструменты

`jwu_issue_attach(key, paths, dry_run=True)` (bash: `jwu issue attach KEY file …`,
требует `--yes`).

`dry_run=True` по умолчанию: вернёт список файлов с размерами, признаком `exists`
и `client_facing` (задача SDESK — вложение увидит клиент). Загрузка — отдельный вызов
с `dry_run=False` после «да».

## Алгоритм

1. **Собери пути.** Файлы берутся из того, что уже собрано локально при разборе;
   ничего не «догружай» из интернета.
2. **Dry-run** — покажи пользователю имена, размеры и предупреждение о содержимом.
   `exists: false` — файла нет, путь неверный: исправь до отправки, jwu не станет
   грузить половину списка.
3. **Загрузи** после «да»: `dry_run=False`.
4. Верни имена и id вложений; запиши в работу, если она есть.

## Чего делать НЕ надо

- Прикладывать файл «чтобы показать» — покажи его содержимое в чате.
- Грузить har/дампы в SDESK, не сказав, что их увидит клиент.
- Класть в задачу секреты и креды: их место в keychain, а не во вложении.

## Связанные скиллы

- **jwu-task-create** — завести задачу.
- **jwu-task-comment** — комментарий к задаче.
- Скачивание вложений задачи — `jwu attachments KEY --download` (отдельной команды-скилла
  для этого нет).
