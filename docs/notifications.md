# Синк, демон и уведомления

## Синк и дельты

`jwu sync` тянет мои задачи, упоминания и PR (с конфликтами, сборками и задачами на
комментах), кладёт снапшот и считает **дельты** — что изменилось с прошлого раза:
`new_comment`, `status_change`, `returned_from_testing`, `qa_comment`, `new_pr`,
`new_pr_comment`, `new_pr_commit`, `reviewer_approved`, `reviewer_needs_work`, `new_conflict`,
`build_failed`/`build_fixed`, `new_pr_task`/`pr_task_resolved`, `pr_all_approved`,
`pr_ready_to_merge`, `gone`/`pr_gone`. Дельты копятся до `jwu changes --clear`.

## Демон

Делает синк регулярным без открытого дашборда:

```bash
jwu daemon run --once               # один проход руками
jwu daemon install --interval 600   # службой: launchd (macOS) / systemd --user (Linux)
jwu daemon kick                     # внеплановый проход прямо сейчас
jwu daemon status · jwu daemon uninstall
```

Один процесс на машину. Раз в `--interval` секунд (от конца прошлого прохода) обходит все
контуры с Jira или GitHub: синк → уведомления → ответы боту. Ошибка одного контура пишется в
лог (`~/.local/share/jwu/daemon.log`) и не мешает остальным. Служба стартует при входе и
перезапускается сама; итог последнего прохода — в `jwu daemon status` и `jwu doctor`.

## Telegram

После **каждого** сетевого синка важные события уходят одним сообщением, ключи — ссылками
на задачу и PR. Если нового нет — бот молчит.

Что приходит:

- проблемы: конфликт, красная сборка, needs work, новая задача в PR;
- задачи: вернули с тестов, комментарий QA, упоминания;
- мои PR: **собрал все апрувы** и **готов к мержу** (все апрувы, сборка зелёная, конфликта нет).

Сообщение делится на два блока: **МОЁ** (я исполнитель, мой PR или задача моего PR) и
**УЧАСТВУЮ** (автор задачи, ревьюер, наблюдаю, упомянули). Под ключом — роль и на ком
задача (`👁 наблюдаю · исп. Иванов`); у смены статуса — ещё и кто перевёл
(`👤 исполнитель · перевёл Мария · на мне`).

Бот двусторонний: между проходами демон держит long polling (`--poll-interval`, 25 с), на
команды реагирует сразу.

| Команда | Что делает |
|---|---|
| `/sync` | проход сейчас; по окончании — итог по каждому контуру («нового нет» / «есть новое» / ошибка) |
| `/status` | когда был последний проход и что накопилось |
| `/stuck` | что застряло по порогам |
| `/mentions`, `/seen` | непрочитанные упоминания; пометить прочитанными |

Ответ на уведомление становится заметкой-контекстом по ключу из него, `ACME-1 текст` —
заметкой по `ACME-1`. Чужие чаты игнорируются.

```bash
jwu configure --non-interactive --telegram-chat <chat_id> --telegram-token "$TELEGRAM_BOT_TOKEN"
jwu notify status · jwu notify test · jwu notify poll
```

Скилл `/jwu-setup-remote` проводит через doctor → daemon → Telegram → синк памяти.
