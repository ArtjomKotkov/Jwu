# Changelog

Раньше история версий жила только в релизах GitHub; дальше — и здесь.

## 2.13.2

- Доска: одна задача — один пункт. Непрочитанное упоминание по задаче, которая уже на доске,
  приклеивается к её пункту («↩ автор: текст»), а не стоит отдельной строкой в «Ответить».
- Несделанная задача с таким комментом берётся с целью «Разбор возврата QA» (jwu-qa-triage).
- Пункт, задачу которого ведёт работа по другому её пункту, помечен «взято (через №N)».
- `jwu_todo_take` возвращает в ответе тот номер, которым пункт попросили, а не номер на свежей доске.

## 2.13.1

- Один инструмент пуша: `jwu_git_push(job_id=…)` пушит ветку рабочей копии работы (папку
  находит сам, проверяет ветку работы, `force` — как у обычного пуша). `jwu_job_push` — устаревший
  алиас, оставлен для сессий на старых скиллах; скиллы, доки и подсказки хука — на `jwu_git_push`.

## 2.13.0

### Доска `jwu todo`
- Номера значат то, что показали сессии: взятие не перенумеровывает доску; `for_worker` берёт
  по доске оркестратора; `keys=[…]` — номер теперь значит другое, и это отказ, а не соседний пункт.
- Работа ревью чужого PR не попадает в «закрыть работу»: «ушло» — PR смержен/закрыт или я больше
  не ревьюер.
- Задачи на мне в любых незакрытых статусах видны: Backlog — в «сделать», статус вне настроек —
  тоже там, с пометкой; в `--json` поле `statuses`.
- После действий jwu (пуш, переход статуса, коммент/ревью/задача/правка PR) доска дотягивает
  затронутое точечно, без синка; пункт помечен «🔄 обновлено jwu ЧЧ:ММ». Дельты и уведомления
  по-прежнему считает синк.
- Старые упоминания (старше 14 дней) не всплывают в «Ответить» новыми.

### Telegram
- Резервный бот: `jwu configure --telegram-backup-token …`. Основной не отвечает — сообщения,
  кнопки и команды идут через резервный; меню резервного помечено, кнопка «Проверить основной бот».
- Длинные сообщения режутся без разрыва HTML-тегов (сводка тихих часов не уходила с ошибкой 400).
- Тихие часы — по местному времени компьютера, а не по поясу ворклогов.

### Git
- Запрос допуска не теряется: ошибка отправки — в журнале, демон досылает; не больше 3 попыток,
  дальше запрос снимается.
- `jwu_job_push`: отказ политики — ответ с причиной, а не пустая ошибка.

### Прочее
- `jwu jobs --on <дата>` / `jwu_jobs(on=…)`: день работ по местному времени (скилл трекинга
  больше не режет UTC).
- План `jwu_worklog_chain` — общий бюджет 60 с на все запросы, дальше понятная ошибка.
- Даты Jira с «+0300» разбираются и на Python 3.10.
